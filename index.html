      How it works
      
    
        
      
      1. Variables stay put.Anything in braces, your signature tag, links, emails and numbers are locked before spinning. They never end up inside a spin block.
        2. 
      
      2. Words, from a cold email phrase bank.Each block only swaps phrases that fit the same spot in a sentence, so every combination reads like English. "a" and "an" get fixed for you.
        3. 
      
      3. Sentences, for the lines everyone writes.CTAs, opt-outs, follow-up bumps and sign-offs get whole-sentence alternatives that keep the same ask.
        4. 
      
      4. Checked by rendering.1,000 random versions get linted for doubled words, broken articles, dashes and spam words before you copy anything.
